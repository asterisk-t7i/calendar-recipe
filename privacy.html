プライバシーポリシー

calendar-recipe（以下「本ツール」）は、開発者本人が個人の予定管理のために使用するツールです。本ツールにおける情報の取り扱いは以下の通りです。

取得する情報

本ツールは、利用者本人の同意のもとで Google カレンダー API を使用し、利用者本人のカレンダー予定（タイトル、日時、場所、説明など）の読み取りと書き込みを行います。

情報の保存場所

Google API の認証情報（credentials.json / token.json）は、利用者本人のデバイス（PC / NAS）内にのみ保存され、開発者のサーバーや第三者のサーバーへ送信されることはありません。本ツールは開発者の管理するサーバーを持たず、すべての処理は利用者本人のデバイス上で完結します。

第三者への提供

取得した情報を第三者へ提供、販売、共有することはありません。

アクセスの取り消し

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」の設定から、本ツールへのアクセス許可をいつでも取り消すことができます。
